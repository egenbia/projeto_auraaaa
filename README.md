#  AURA – Assistente Inteligente para Leitura de Artigos Científicos

O AURA é uma aplicação web desenvolvida com Python (Flask) e MySQL, voltada para auxiliar estudantes e pesquisadores na leitura, compreensão e análise de artigos científicos por meio de recursos automatizados como geração de resumos, palavras-chave, perguntas, classificação temática, citações e leitura em áudio.

O projeto te como objetivo facilitar o processo de leitura e estudo de artigos científicos, oferecendo ferramentas que auxiliam na compreensão do conteúdo, organização das informações e acessibilidade, especialmente para estudantes da área acadêmica.



##  Contexto Acadêmico

Este projeto foi desenvolvido como Projeto Integrador do curso de Desenvolvimento de Software Multiplataforma da FATEC de Registro.



##  Funcionalidades

-  Sistema de autenticação
- Leitura de artigos científicos
 - Geração de resumo
 - Leitura em áudio
 - Seleção de resumo
 - Perguntas sobre o artigo
 - Classificação temática
 - Citações
 - Gerenciamento de dados

##  Tecnologias Utilizadas

### Backend
- Python
- Flask — Framework web
- MySQL — Banco de dados relacional
- mysql-connector-python — Conexão com o banco

### Frontend
- HTML5
- CSS3
- Templates Jinja2
